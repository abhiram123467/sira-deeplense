## 🌍 Why This Matters

The SIR model has guided **every major epidemic response** — COVID-19, Ebola, flu pandemics. Yet fitting its parameters from noisy real-world data remains hard, and extending it (SEIR, network SIR, spatial SIR) requires hand-crafting new equations each time.

**SIRA asks a different question:** What if we could train a neural network to *discover* epidemic dynamics directly from time-series observations — without pre-specifying the ODE structure?

This is the same philosophy behind **Physics-Informed Neural Networks (PINNs)** used in gravitational lensing (DeepLense). SIRA is its epidemiological sibling.

## 📐 The SIR Model — Mathematical Background

The classic SIR model describes epidemic spread via **3 coupled ODEs**:

```
dS/dt = -β·S·I / N          (Susceptible → Infected)
dI/dt =  β·S·I / N - γ·I   (Infected → Removed)
dR/dt =  γ·I                (Removed accumulates)

Where:
  S = Susceptible population    (fraction at risk)
  I = Infected population       (active cases)
  R = Removed (recovered + deceased)
  β = Transmission rate         (disease spread speed)
  γ = Recovery rate             (1/γ = mean infectious period)
  N = Total population          (fixed = 1000)

  R₀ = β/γ  ← Basic Reproduction Number
         R₀ > 1  → epidemic grows  🔴
         R₀ < 1  → epidemic dies out  🟢
         R₀ = 1  → critical threshold ⚠️
```

### Three Epidemic Regimes Simulated

```
R₀ = 3.0 (β=0.3, γ=0.1)      R₀ = 5.0 (β=0.5, γ=0.1)      R₀ = 8.0 (β=0.8, γ=0.1)
──────────────────────         ──────────────────────         ──────────────────────
S ████████░░░░░░░░             S ████░░░░░░░░░░░░░░           S ██░░░░░░░░░░░░░░░░░

Low spread — long tail         Medium — sharp peak            High — fast, severe
```

## 🎲 Dataset Generation — Gillespie Algorithm

```
For each of 2,000 epidemic simulations:

  1. Sample (β, γ) uniformly:
       β  ∈ [0.1, 0.9]   (transmission rate)
       γ  ∈ [0.05, 0.3]  (recovery rate)
       → R₀ range: ~0.33 to ~18

  2. Simulate stochastic SIR via Gillespie algorithm:
       At each step, compute event rates:
         rate_infect  = β·S·I / N
         rate_recover = γ·I
         total_rate   = rate_infect + rate_recover

       Time to next event: Δt ~ Exponential(1 / total_rate)
       Which event:        p(infect)  = rate_infect / total_rate
                           p(recover) = rate_recover / total_rate

  3. Use deterministic RK45 solution as training target
       (mean of stochastic ensemble → smooth ground truth)

  4. Output: curve (S/N, I/N, R/N) sampled at t = 0, 1, ..., 160 days

Dataset: 2,000 × 161 × 3  (samples × timesteps × compartments)
Split:   80% train / 10% val / 10% test
```

```
│           ▼            ▼            ▼                      │
│   ┌──────────────┐ ┌──────────┐ ┌───────────────┐         │

│   │  Baseline    │ │ ODE      │ │               │         │
│   │              │ │ (Main)   │ │               │         │
│   └──────────────┘ └──────────┘ └───────────────┘         │
│           │            │            │                      │
│           ▼            ▼            ▼                      │
│        S(t), I(t), R(t) predictions (t = 0 → 160 days)    │
└─────────────────────────────────────────────────────────────┘
```

---

### Model 1 — MLP Baseline

```
Input: [β, γ]  →  (B, 2)
       │
       ▼
  Linear(2 → 256) → SiLU
  Linear(256 → 256) → SiLU    × 4 layers
  Linear(256 → 161×3)
       │
       ▼
  Reshape → (B, 161, 3)   [S, I, R at each timestep]
```
*Fast but ignores temporal structure — treats each time step independently.*

---

### Model 2 — Physics-Informed Neural ODE ⭐ (Main Model)

```
Input: [β, γ]  →  (B, 2)
       │
       ▼
┌──────────────────────────────────────────────────────────┐
│  Parameter Encoder                                       │
│  Linear(2 → 64) → Tanh → Linear(64 → 128) → Tanh        │
│  Output: context vector  (B, 128)                        │
└─────────────────────┬────────────────────────────────────┘
                      │ context injected at every ODE step
                      ▼
┌──────────────────────────────────────────────────────────┐
│  ODE Function f(state, t, context)                       │
│                                                          │
│  state = [S, I, R]     ← current epidemic state         │
│  t     = scalar time   ← normalised to [0, 1]           │
│  context = encoded β,γ ← epidemic parameters            │
│                                                          │
│  Input: concat([state, context, t])  → (B, 3+128+1=132) │
│  Linear(132 → 256) → SiLU                               │
│  Linear(256 → 256) → SiLU  ×4 layers                    │
│  Linear(256 → 3)   → d[S,I,R]/dt                        │
└─────────────────────┬────────────────────────────────────┘
                      │ torchdiffeq.odeint (adaptive RK4/5)
                      ▼
             S(t), I(t), R(t)  at t = linspace(0,1,161)
```

**Physics Constraint Loss** — enforces epidemic conservation laws:
```python
L_physics = | S(t) + I(t) + R(t) - 1 |²    # population must sum to 1
           + ReLU(-S)² + ReLU(-I)² + ReLU(-R)²   # no negative populations

Total Loss = MSE(pred, true)  +  0.1 × L_physics
```

---

### Model 3 — Symbolic SIR (Analytic Approximation)

```
Learns closed-form parametric equations — inspired by known SIR solutions:

S(t) ≈ sigmoid decay:
        S(t) = 1 / (1 + exp(a·β/γ · (t − t₀/(β/γ))))
        Learnable: a, t₀

I(t) ≈ Gaussian bell curve:
        I(t) = A·(β/γ − 1) · exp(−0.5 · ((t − peak/R₀) / σ/R₀)²)
        Learnable: A, peak, σ

R(t) = 1 − S(t) − I(t)     (enforced by conservation)

Why? → Interpretable, R₀-dependent, deployable without a GPU
```

### Training Configuration

```
Optimizer  : AdamW  (β₁=0.9, β₂=0.999, weight_decay=1e-4)
Scheduler  : CosineAnnealingLR
Epochs     : 80
Batch size : 64
LR (MLP)   : 1e-3
LR (ODE)   : 5e-4  (lower — ODE integration is more sensitive)
Phys. wt.  : 0.1
Grad clip  : max_norm = 1.0
Seed       : 42 (fully reproducible)
```
